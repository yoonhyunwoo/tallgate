동작 방식

앱을 고치지 않고, 화면만 읽습니다

TallGate는 안드로이드 접근성 서비스로 인스타그램, 유튜브, 틱톡 화면의 구성 요소를 확인합니다. 원본 앱은 수정하지 않습니다.

1️⃣

감지

대상 앱 3종의 화면 전환과 콘텐츠 변경 이벤트만 받아서, 숏폼 화면에만 있는 요소를 찾습니다.

2️⃣

복귀

숏폼으로 판단되면 탭을 전환하거나 뒤로가기를 눌러 이전 화면으로 되돌립니다.

3️⃣

알림

설정에 따라 진동과 안내 메시지를 보여주고, 연속 오작동을 막기 위해 0.8초간 쉽니다.

5분이면 설치됩니다

Google Play 스토어에는 아직 올라가 있지 않습니다. GitHub Releases에서 APK 파일을 받아 직접 설치하세요.

APK 다운로드

휴대폰 브라우저에서 아래 버튼을 눌러 TallGate.apk를 받습니다. 이전 버전은 Releases 페이지에서 받을 수 있습니다.

TallGate.apk 다운로드 릴리스 노트

알 수 없는 앱 설치 허용

다운로드한 파일을 열면 설치 차단 안내가 뜰 수 있습니다. 설정으로 이동해서 사용 중인 브라우저(또는 파일 앱)에 이 출처 허용을 켜 주세요.

설치하고 앱 열기

설치를 누르고 완료되면 TallGate를 엽니다. 처음에는 위쪽에 접근성 서비스 권한 필요 안내가 보입니다.

접근성 권한 켜기

권한 설정하러 가기를 누르면 접근성 설정이 열립니다.

  • 설정 → 접근성 → 설치된 앱(또는 다운로드한 앱) → TallGate를 사용으로 바꿉니다.
  • 기기에 따라 메뉴 이름이 조금 다를 수 있습니다.

차단할 항목 고르기

TallGate 화면에서 막고 싶은 앱의 스위치를 켭니다. 접근성이 켜지면 안내가 사라지고, 바로 적용됩니다.

접근성 스위치가 회색이라 못 켜나요? Android 13 이상에서는 스토어 밖에서 설치한 앱의 접근성 권한이 기본으로 막혀 있습니다. 설정 → 앱 → TallGate → 오른쪽 위 ⋮ → 제한된 설정 허용을 먼저 누른 뒤 다시 접근성 설정으로 가세요.
FAQ

자주 묻는 질문

접근성 권한이 왜 필요한가요?

다른 앱 화면에 숏폼 요소가 떠 있는지 읽고, 탭 전환이나 뒤로가기를 대신 눌러야 하기 때문입니다. 이를 위한 권한이 접근성 서비스뿐입니다. TallGate는 대상 앱 3종의 이벤트만 받도록 제한되어 있습니다.

내 화면이나 데이터가 어딘가로 전송되나요?

아니요. 앱은 인터넷 권한을 선언하지 않아서 네트워크 통신 자체가 불가능합니다. 저장하는 것은 스위치 설정값뿐이고 기기 안에만 있습니다.

Google Play에는 왜 없나요?

다른 앱을 감시·제어하는 접근성 앱은 Google Play의 접근성 API 정책상 별도 고지·동의 절차와 심사가 필요합니다. 현재는 GitHub Releases로만 배포합니다.

인스타·유튜브 앱이 업데이트되면 어떻게 되나요?

TallGate는 각 앱 화면의 구조를 기준으로 감지합니다. 앱 업데이트로 화면 구조가 바뀌면 일부 차단이 동작하지 않을 수 있습니다. 그럴 때는 Issues에 앱 버전과 함께 알려주시면 반영합니다.

앱을 업데이트하면 접근성이 꺼지나요?

새 APK를 덮어 설치한 뒤 접근성 서비스가 꺼져 있다면 설정에서 다시 켜 주세요. 앱 첫 화면의 안내가 상태를 알려줍니다.

삭제는 어떻게 하나요?

먼저 접근성 설정에서 TallGate를 끄고, 일반 앱처럼 삭제하면 됩니다.
