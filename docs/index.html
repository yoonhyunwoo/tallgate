How It Works

Real-time UI inspection without app modifications

TallGate uses Android's Accessibility Service to monitor specific view hierarchy components in supported apps.

1️⃣

Filter

Listens only to window state and content changes from Instagram, YouTube, and TikTok.

2️⃣

Detect & Redirect

Identifies short-form container IDs and triggers a tab switch or system back action.

3️⃣

Debounce

Applies an 800ms debounce cooldown to prevent loops, accompanied by optional haptic and toast alerts.

Installation

Sideloading Guide

TallGate is distributed directly as an APK via GitHub Releases.

Download the APK

Download TallGate.apk using your Android browser. Previous builds are available on the Releases page.

Download TallGate.apk Release Notes

Allow Installation from Browser

If prompted when opening the APK, tap Settings and enable Allow from this source for your browser or file manager.

Install & Launch

Tap Install and open TallGate. The home screen will show a banner indicating that the Accessibility Service is inactive.

Enable Accessibility Service

Tap the banner or Enable Service to open Android settings.

  • Navigate to Settings → Accessibility → Installed apps (or Downloaded apps) → TallGate and switch it On.
  • Menu labels may vary slightly depending on device manufacturer.

Configure Rules

Return to TallGate and toggle the feeds you want to block. Once enabled, blocking applies immediately.

Accessibility switch greyed out? On Android 13+, accessibility permissions for sideloaded apps are restricted by default. Go to Settings → Apps → TallGate → three-dot menu (⋮) → Allow restricted settings, verify with PIN/biometrics, then return to Accessibility settings.
FAQ

Frequently Asked Questions

Why does TallGate require Accessibility permissions?

TallGate needs to inspect active view hierarchies to detect short-form containers and perform tab switches or back navigations. Android's Accessibility Service is the only official API capable of cross-app view inspection without root or app tampering. Events are strictly scoped to the three supported apps.

Is any screen content or personal data transmitted?

No. TallGate does not declare the INTERNET permission, making network communication impossible. Only your toggle settings are saved, entirely on-device.

Why isn't TallGate on Google Play?

Google Play policies heavily restrict Accessibility Service usage to assistive tools for people with disabilities. Because TallGate automates cross-app navigation, it is distributed independently via GitHub Releases.

What happens when Instagram or YouTube updates?

TallGate relies on specific UI view IDs and component names. If an app update modifies these internal IDs, blocking may temporarily fail until updated. If you notice a broken screen, please file an issue on GitHub with your app version.

Does the service turn off after updating TallGate?

If Android turns off the Accessibility Service after updating the APK, re-enable it in Accessibility settings. The in-app banner reflects current service status.

How do I uninstall TallGate?

Disable TallGate in Accessibility settings first, then uninstall it like any standard Android app.
