TallGate는 숏폼 영상 피드가 열리는 즉시 화면을 닫거나 이전 화면으로 이동합니다.

[지원 피드]
• Instagram: 홈 '추천' 탭을 일반 피드로 전환하고, 전체 화면 릴스 실행 시 뒤로 가기를 수행합니다. (DM 대화창 유지)
• Instagram 탐색 탭: 탐색(검색) 탭 진입 시 홈 피드로 이동합니다. (기본값 꺼짐)
• YouTube 쇼츠: 쇼츠 플레이어가 열리면 즉시 뒤로 이동합니다. 일반 영상은 정상 재생됩니다.
• TikTok: 추천(For You) 피드 진입 시 즉시 벗어납니다.

[주요 기능]
• 피드별 개별 설정: 각 피드 차단 여부를 개별적으로 켜거나 끌 수 있습니다.
• 차단 알림: 피드가 차단될 때 진동 및 토스트 알림을 선택할 수 있습니다.
• 네트워크 권한 없음: 인터넷 권한(android.permission.INTERNET)을 요청하지 않습니다. 외부 데이터 전송, 계정 생성, 광고, 분석 트래커가 일체 없습니다.
• 로컬 저장: 피드 차단 및 알림 설정은 기기 내부 저장소에만 보관됩니다.

[접근성 서비스 API 사용 안내]
TallGate는 숏폼 영상 피드를 감지하고 화면을 벗어나기 위해 Android AccessibilityService API를 사용합니다.

• 접근 정보: 대상 앱(Instagram, YouTube, TikTok)이 활성화되어 있을 때 UI 노드 식별자, 뷰 라벨, 선택된 탭 정보만 메모리에서 확인합니다. 그 외 앱의 이벤트는 수신하지 않습니다.
• 수행 동작: 숏폼 화면 감지 시 시스템 뒤로 가기를 실행하거나 기본 피드 탭으로 전환하며, 설정된 진동·토스트 알림을 표시합니다.
• 데이터 보호: 화면 내용이나 개인정보를 기록, 저장, 전송하지 않으며 메모리에서 일시적으로 판단한 뒤 즉시 파기합니다.

접근성 서비스는 첫 실행 시 표시되는 안내에 동의해야 활성화되며, Android 설정 > 접근성에서 언제든지 끌 수 있습니다.

[요구 사양 및 안내]
• 지원 환경: Android 8.0 이상
• 면책 고지: TallGate는 Meta(Instagram), Google(YouTube), TikTok과 관련 없는 독립 유틸리티입니다. 각 상표권은 해당 소유자에게 있습니다.
